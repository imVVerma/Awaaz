## 5. Build the backend around safe business actions

This is the most important engineering decision in Awaaz.

Do not let the LLM generate arbitrary SQL or decide whether a payment reminder has been sent. Instead, make it translate the user's request into a small, validated set of supported actions.

For example, the user says\:

> “Mujhe batao kaunse products ka stock kam hai.”

The backend should turn that into a structured intent, not a free-form answer.

```json

{
  "intent": "list_low_stock",
  "entities": {},
  "requires_confirmation": false
}
```

The backend then executes a predefined query, checks the returned records, and builds a response from those results.

```python

# Illustrative application logic, not a Gnani SDK example.

def handle_business_intent(intent, db):
    if intent == "list_low_stock":
        return db.list_low_stock_products()

    if intent == "list_outstanding_balances":
        return db.list_outstanding_balances()

    if intent == "draft_payment_reminder":
        return db.prepare_payment_reminder()

    return {
        "error": "unsupported_intent",
        "message": "I could not identify a supported action."
    }
```

The example assumes you implement the database methods and a validated intent schema.

### Essential safeguards

- **Grounded answers\:** quantities, balances, and totals must come from database queries.
- **Ambiguity handling\:** if the user names a customer or product that cannot be identified uniquely, ask for clarification.
- **Confirmation before consequential actions\:** any future write or external communication requires explicit approval.
- **Failure transparency\:** if the API fails, say so rather than inventing a transcript or answer.
- **Visible transcript\:** users should be able to inspect and correct what was heard.
- **Audit trail\:** log the intent, result status, and timing without unnecessarily retaining voice recordings or sensitive data.

For the MVP, the three business workflows can be implemented as explicit backend functions. This is easier to test, explain in an interview, and make reliable than a general-purpose agent.
